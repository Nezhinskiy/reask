# schetovod

Сервис счетов. Работает в Ардении, НДС 20%.

Выставляет счета двум видам покупателей:

- частным лицам, которые оформили заказ в интернет-магазине «Витрина» (корзину и оформление
  заказа ведёт команда Витрины, их код в другом репозитории);
- компаниям, которые покупают по договору. У компании есть налоговый номер (`buyer_tax_id`).

Сейчас около 70% счетов выставляется компаниям.

## Код

- `billing/models.py` — счёт и его позиции, суммы без налога.
- `billing/vat.py` — расчёт НДС.
- `billing/render.py` — печатная форма счёта.
- `tests/` — тесты расчёта.
