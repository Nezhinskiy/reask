# Онбординг новой школы

1. **Школа.** Название, адрес, реквизиты.
2. **Ученики и семьи.** Список учеников с родителями и номерами договоров (вручную или из таблицы).
3. **Выписка.** Школа загружает CSV-выписку из банка за прошлый учебный год. Каждая строка —
   платёж родителя; `importer/` находит семью по ФИО плательщика или номеру договора в
   назначении платежа и записывает проводку в `ledger-api`.
4. **Балансы.** Экран «Балансы» показывает долг или переплату каждой семьи, внизу — «Итого за
   год». Этот же экран директор школы видит у себя в тот же день.

Шаг 3 можно пропустить и загрузить выписку позже из настроек.
