# Камертон

Веб-приложение для частных музыкальных школ: ученики, абонементы и оплаты родителей. Пользуются
им администраторы и бухгалтеры школ, обычно один человек на школу.

Новая школа проходит онбординг из четырёх шагов (docs/onboarding.md). На третьем шаге она
загружает выписку из банка (CSV) за прошлый учебный год, чтобы балансы семей с первого дня были
верными.

- `importer/` — разбор выписки, проверка строк и запись проводок в `ledger-api`.
- `ledger-api` — наш сервис проводок (отдельный репозиторий); балансы и отчёты строятся по нему.
- `analytics/` — выгрузки продуктовой аналитики, обновляются раз в месяц.
