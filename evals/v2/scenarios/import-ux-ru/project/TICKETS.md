# Задачи

## ONB-12: первый импорт выписки — что видит школа, если часть строк не прошла

Сейчас при любой ошибке импорт откатывается целиком, и школа видит одно сообщение: «Не удалось
загрузить файл. Попробуйте ещё раз». Какие строки не прошли и почему, не показывается. Нужно
решить, что школа видит вместо этого, до запуска осенней рекламной кампании 16 ноября: после
неё ждём около 300 новых школ в месяц.

## ONB-9 (закрыта): проводки пишутся в ledger-api по одной

Импорт больше не пишет в базу напрямую: каждая строка выписки отправляется в `ledger-api`
отдельным запросом с таймаутом 3 секунды.
