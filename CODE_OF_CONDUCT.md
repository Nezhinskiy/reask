# Code of Conduct

This project adopts the [Contributor Covenant, version 2.1][covenant] in full. Read it there rather
than here, so this file cannot drift out of step with the version it names.

[covenant]: https://www.contributor-covenant.org/version/2/1/code_of_conduct/

In short: everyone taking part in this project's issues, pull requests, discussions and reviews is
expected to be respectful, to assume good faith, and to accept that technical disagreement is
normal and personal attacks are not. Criticise the wording, the design or the argument, never the
person who wrote it.

## Reporting

Report behaviour that breaks this code privately through
<https://github.com/Nezhinskiy/reask/security/advisories/new>, and say in the first line that it
is a conduct report rather than a vulnerability. That channel is private to the maintainer and is
reused here until a dedicated contact address is published. Reports are handled confidentially.
